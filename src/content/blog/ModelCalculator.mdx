# Estimating Model Performance based on hardware

  So I bought a used AMD RX6800 GPU 3 years ago with my first paycheck. I thought that 16 GB of VRAM would be plenty to fit LLMs I'd always been gaming on way less...
  It turned out not only to be insufficient but also trapped out of the mainstream inference ecosystem (CUDA). When I discovered that RocM size would exceed Skyrims, it picked my curiosity.
  I managed to run a few llms since then and wanted to share a way to estimate if the model you are dreaming of can run on your GPU.

This calculator makes a lot of assumptions and estimates should be seen as an upper bound for past models and in some case a lower bound for recent ones. Be aware that it applies only to transformer architecture and even if CUDA and RocM are mentionned, they are not taken into account.
